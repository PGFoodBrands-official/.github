# Support

Use GitHub issues for reproducible defects and repository-specific feature requests. Search existing issues first and include the smallest amount of information needed to reproduce or assess the request.

For access problems, production incidents, sensitive operational matters, or requests containing confidential business information, use the established internal support or incident channel and contact the repository maintainer. Include the repository, environment, workflow or run ID, and approximate timestamp, but never include credentials, tokens, customer data, or unredacted logs.

Suspected vulnerabilities must follow [SECURITY.md](SECURITY.md).
