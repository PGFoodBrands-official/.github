# PG Food Brands Engineering

Welcome to the GitHub organization of **PG Food Brands**.

This organization hosts the software, automation, data, and cloud infrastructure projects maintained by PG Food Brands.

## Our engineering approach

We design and operate our technology with an emphasis on:

* secure-by-default infrastructure;
* infrastructure managed as code;
* clear separation between environments;
* least-privilege access;
* automated and reproducible deployments;
* centralized secrets management;
* observability, reliability, and cost awareness;
* documented and reviewable changes.

Our cloud platforms are built primarily on **Google Cloud**, using modern engineering practices to support secure and maintainable systems.

## Repositories

Most operational repositories are private because they contain business-specific applications, infrastructure definitions, and internal automation.

Public repositories, when available, contain reusable tools or components that may be useful to the wider community.

## Security

Security issues should not be disclosed through public issues or discussions.

Please report potential vulnerabilities privately using the security policy provided in the relevant repository or through the official PG Food Brands contact channels.
