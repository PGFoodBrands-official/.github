# Security policy

## Reporting a vulnerability

Do not report suspected vulnerabilities through a public issue, discussion, pull request, commit, or build log.

PG Food Brands organization members should contact the repository maintainer or an organization owner through the established internal security or escalation channel.

External reporters should contact PG Food Brands privately through an official company contact channel and clearly identify the message as a security report. The official website is [pgfoodbrands.com](https://pgfoodbrands.com/).

Include, where possible:

- the affected repository, component, and version or commit;
- a concise description of the issue and its potential impact;
- reproducible steps or a minimal proof of concept;
- relevant logs or screenshots with secrets and personal data removed;
- any mitigation already tested.

PG Food Brands will coordinate validation, remediation, and disclosure with the reporter. Please allow time for a fix before sharing details publicly.

## Scope

This policy applies to actively maintained repositories in the `PGFoodBrands-official` organization unless a repository publishes a more specific policy.
